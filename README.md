# MediKiosk
Patient Case-Taking Software
MediKiosk is a digital patient case-taking system designed to collect structured patient information through guided clinical questioning, multilingual voice interaction, and medical document extraction.

The system converts patient-provided information into a structured case history and generates a concise, doctor-friendly summary to assist healthcare professionals during consultation.

MediKiosk is designed to support doctors and patients by improving the organization and accessibility of patient information. The AI assists with summarization and information extraction but does not independently diagnose medical conditions
# Tech Stack

- **HTML** — Page structure
- **CSS** — Styling and UI
- **JavaScript** — Frontend logic
- **VS Code** — Frontend development

# Backend
- **Python** — Backend development

# Database
- **PostgreSQL** — Patient data and structured case history storage

# Clinical Question Engine
- **JSON** — Clinical question trees and branching logic
- **SOCRATES Framework** — Structured symptom/pain history

# Voice AI
- **Bhashini** — Automatic Speech Recognition (ASR) and Text-to-Speech (TTS)

# Document AI
- **Google Document AI** — OCR and medical document text extraction

# Summarization AI
- **Claude API** — AI-assisted extraction, organization and generation of structured patient summaries
